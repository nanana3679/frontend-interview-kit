# /study — 학습 세션 시작

학습 세션을 시작하거나 이어서 진행할 때 사용하는 skill이다.

## 동작 절차

1. `ko/progress.md` 파일이 존재하는지 확인한다.
   - 없으면 CLAUDE.md의 파일 형식 템플릿을 기반으로 새로 생성한다.
   - `시작일`에 오늘 날짜를, `현재 주차`에 `1-2주`를 기입한다.

2. `ko/progress.md`를 읽어 다음 정보를 파악한다:
   - 현재 주차 (`현재 주차` 필드)
   - 각 주차별 완료/미완료 항목 수

3. 전체 진행률 요약을 보여준다:
   ```
   📊 전체 진행률: 12/30 (40%)
   📍 현재 주차: 3-4주 (React 심화)
   📅 최근 학습일: 2026-03-08

   ### 3-4주: React 심화 (2/5 완료)
   - [x] React.dev 공식 문서 학습
   - [x] Developer Way 영상 시청
   - [ ] Jack Herrington 영상 시청
   - [ ] 연습: useReducer로 할 일 앱 만들기
   - [ ] 연습: Redux vs Zustand vs Jotai 비교
   ```

4. 현재 주차에서 다음으로 해야 할 항목을 안내한다.

5. `ko/progress.md`의 `최근 학습일`을 오늘 날짜로 갱신한다.

## 인자

- `/study` — 현재 주차 이어서 학습
- `/study 5-8주` — 특정 주차로 이동하여 학습 (현재 주차도 변경)
