# /done — 학습 항목 완료 처리

학습 항목을 완료 처리하고 진행률을 업데이트하는 skill이다.

## 동작 절차

1. `ko/progress.md`를 읽는다. 파일이 없으면 `/study`를 먼저 실행하라고 안내한다.

2. 사용자가 지정한 항목을 찾아 `[ ]`를 `[x]`로 변경한다.
   - 완료 날짜를 항목 뒤에 추가한다: `- [x] 항목명 ✓ 2026-03-09`

3. 항목 매칭 방식:
   - `/done Promise.all` → "연습: Promise.all 직접 구현" 항목을 찾아 완료 처리
   - `/done 1` → 현재 주차의 첫 번째 미완료 항목을 완료 처리
   - `/done 1,3,5` → 현재 주차의 1, 3, 5번째 미완료 항목을 완료 처리
   - `/done all` → 현재 주차의 모든 미완료 항목을 완료 처리

4. `최근 학습일`을 오늘 날짜로 갱신한다.

5. 업데이트된 진행률을 보여준다:
   ```
   ✅ 완료: "연습: Promise.all 직접 구현"

   📊 5-8주 진행률: 5/9 (56%)
   📊 전체 진행률: 18/30 (60%)

   다음 할 일: Namaste JavaScript 시청
   ```

6. 해당 주차의 모든 항목이 완료되면:
   - 축하 메시지를 출력한다.
   - `현재 주차`를 다음 주차로 자동 갱신한다.
   - 다음 주차의 학습 내용을 안내한다.

## 응답 언어

반드시 한국어로 응답한다.
